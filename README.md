# Wavehouse

Welcome to the Wavehouse Map Android Application!

## Overview
This application is designed to be a mapping solution for Android, featuring location tracking, style customization, POI search, and 3D map scene visualization via MapLibre, Filament, and Sceneview.

## Tech Stack
- Kotlin
- Android SDK (ViewBinding, DataBinding, CameraX)
- MVVM, Hilt, Retrofit, Coroutines
- MapLibre, Filament, Sceneview

## Build & Run
To run the project locally, open Android Studio in the `AndroidStudioProjects/Map/` directory and run via the standard Gradle Build tasks. Minimum API is 24, Target API is 34.
