# Project Roadmap

## Phase 1: Foundation and Initial Tooling
- Setup basic map SDK rendering.
- Integrate initial layouts for search and routing.
- Configure Retrofit and backend connectivity.

## Phase 2: Core Map Features
- Complete UI for location tracking and map panning.
- Finish Auto-complete suggestions for places/points of interest.
- Implement UI for choosing distinct Map Styles.

## Phase 3: Advanced Integrations
- Integrate 3D mapping using filament and Sceneview.
- Camera and AR functional integrations (CameraX).
- Crashlytics, profiling, and thorough QA.
