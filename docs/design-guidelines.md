# Design Guidelines

## Color Palette
- Primary colors configured in `colors.xml`.
- Support for Night mode via values-night themes.

## Typography and Assets
- Use standard Material Design specs for gaps and typography settings.
- Implement robust vector drawables and avoid hardcoded pixel specs. Maintain responsive dp and sp spacing.

## Layout Configuration
- Focus on clean aesthetics utilizing Material UI elements.
- Constraints heavily leaning on ConstraintLayout for robust responsiveness across multiple device screens.
