# Project Overview & PDR (Product Development Requirements)

## 1. Project Overview
Project Name: wavehouse (Map Application)
Platform: Android
Description: A mobile application providing map functionalities, search navigation, custom map styling, and potentially Maplibre integrations with 3D/AR capabilities using Filament/Sceneview.

## 2. Product Development Requirements
- **Features**: Implement search capabilities, view styling maps on the device, handle routing/navigation, display 3D/GLTF scenes.
- **Tools Integrations**: Retrofit for remote APIs, Hilt for Dependency Injection, Google Maps SDK/MapLibre, Filament/Sceneview for 3D functionalities.
